[sealed bidding bot](http://doc.dreev.es/sealedbids).

[tauction.dreev.es](https://tauction.dreev.es)

[a Google Sheet](https://docs.google.com/spreadsheets/d/1hclphAZ3zQIq14Nip1ZxTDSoE9ygXqAv27RwP1hiMA8/edit).
